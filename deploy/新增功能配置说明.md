# 智能分类、邮箱注册与管理员配置

## 配置位置与启动

本机复制 `clouddrive/local.env.ps1.example` 为 `clouddrive/local.env.ps1`，填写配置后执行 `run.ps1`。这个私有文件已经被 Git 忽略。服务器在 `/opt/clouddrive/clouddrive.env` 中填写对应环境变量，然后重启后端服务；前端重新执行 `npm run build` 并更新部署的 `dist`。

`.env.example` 只是配置样例。直接运行 Java 时不会自动加载 `.env`，需要通过启动环境或 systemd 的 `EnvironmentFile` 注入。不要把 API Key、SMTP 授权码或管理员口令放进前端代码。

应用启动时自动执行新增的 V9、V10 数据库迁移，保留旧账号和文件。旧账号仍可用用户名登录；新注册必须验证邮箱，旧账号尚未绑定邮箱时由管理员协助重置密码。

## 邮箱注册与找回密码

填写 `CLOUD_DRIVE_SMTP_HOST`、`CLOUD_DRIVE_SMTP_PORT`、`CLOUD_DRIVE_SMTP_USERNAME`、`CLOUD_DRIVE_SMTP_PASSWORD`、`CLOUD_DRIVE_MAIL_FROM`。密码通常使用邮箱服务商提供的 SMTP 授权码，发件地址须符合该服务商要求。

默认使用 587 端口、SMTP 认证和 STARTTLS。若服务商要求 465 端口的隐式 SSL，设置 `CLOUD_DRIVE_SMTP_PORT=465`、`CLOUD_DRIVE_SMTP_SSL=true`、`CLOUD_DRIVE_SMTP_STARTTLS=false`。按邮箱服务商要求配置，SSL 与 STARTTLS 不应同时开启。

验证码有效期为 10 分钟，同一邮箱同一用途发送间隔为 60 秒，最多允许 5 次错误尝试，成功使用后失效。注册与找回密码使用不同用途的验证码。验证码不会通过接口、日志或页面直接返回。未正确配置 SMTP 时，发送接口会明确报错，不会伪装发送成功。

另有基于 Redis 的来源地址限流，默认每 600 秒最多请求 20 次，可用 `CLOUD_DRIVE_MAIL_IP_LIMIT`、`CLOUD_DRIVE_MAIL_IP_WINDOW_SECONDS` 调整。应用默认不解析转发头；同机 Nginx 部署应设置 `SPRING_PROFILES_ACTIVE=deploy` 并使用配套 Nginx 配置，后端只监听本机且仅信任本机代理，由 Nginx 覆盖外来转发头后传递真实来源 IP，避免全站共用代理桶或伪造来源绕过。来源 IP 限流与邮箱/用途冷却同时保留，同一 NAT 出口仍共享来源 IP。详细边界见 [部署说明](部署说明.md#发码来源地址与可信代理)。

注册需要邮箱、验证码、用户名和密码。登录仍使用用户名和密码；忘记密码时使用注册邮箱收取验证码并设置新密码。

## 首次创建管理员

同时设置以下三项后启动应用：

```text
CLOUD_DRIVE_ADMIN_USERNAME=自行设置的管理员用户名
CLOUD_DRIVE_ADMIN_PASSWORD=自行设置的强口令
CLOUD_DRIVE_ADMIN_EMAIL=自己的真实邮箱
```

仅创建不存在的新管理员账号，不会自动提升同名普通账号，也不会在每次重启时修改管理员密码。没有内置管理员账号或默认管理员密码。创建成功后可从运行配置中移除这三项。

管理员登录后可在“用户管理”查看账号、禁用/启用账号、重置密码、调整角色。普通用户调用管理员接口会被服务端拒绝。密码重置、禁用和角色调整后，该账号的旧登录令牌失效，需要重新登录。系统保护最后一个可用管理员，且不允许管理员禁用自己。

## 管理员账号扩容

管理员在“用户与权限管理”中点击目标账号的“扩容”，选择扩容后的总容量并确认。桌面列表和手机卡片均提供入口，支持整数GiB输入及5、10、20、50、100 GiB快捷选项；只允许增加，当前每账号上限为100 GiB。

接口为`PATCH /api/admin/users/{id}/quota`，请求体`{"quotaBytes":5368709120}`表示将总容量设为5 GiB，不是再增加5 GiB。重复提交相同值不叠加，较小值返回409，未登录返回401、普通用户返回403。权限由后端检查，更新与上传配额校验共用账号行锁。

功能复用已有`user_account.quota_bytes`字段，不增加表或数据库迁移。扩容不改变已使用空间、账号身份及登录令牌；被扩容的用户通过账号菜单“刷新配额”查看新值，管理员为自己扩容时页面自动刷新侧栏。

该功能只分配逻辑配额，不增加物理磁盘，不接腾讯云扩盘接口，也不包含付费或申请审批。服务器的4核4GB是CPU和内存配置，实际容量应根据磁盘剩余空间分配。扩容不会调整默认200MB的上传请求上限。部署时更新后端程序与前端dist，不需要手工修改数据库配额或表结构。

## DeepSeek 智能分类

设置 `DEEPSEEK_API_KEY` 后重启后端。可配置：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | API 地址 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 模型名称，须与账号可用模型一致 |
| `DEEPSEEK_TIMEOUT_SECONDS` | `30` | 单次请求超时 |
| `AI_MAX_TEXT_BYTES` | `24000` | 单个文件最多读取的文本字节数 |
| `AI_REVIEW_ENABLED` | `false` | 未保存管理员设置时的辅助审核默认值 |

上传完成后异步分析，结果显示在文件列表，可按类别筛选、手动重新分析。分类保存为文件元数据，不移动文件或改变目录结构。普通上传、秒传、分片合并、分享转存均触发分析；旧文件可在列表中手动发起分析。

文本、Markdown、CSV、JSON、源代码等支持有限文本摘录；图片、音视频、压缩包及其他不支持提取的二进制文件只根据文件名和后缀进行分析，不会声称已经读取它们的实际内容。当前不包含图片识别、音视频识别、OCR、PDF/Office 全文解析或病毒扫描。

配置 Key 后会向 DeepSeek 发送文件名、后缀及支持的有限文本摘录。对敏感文件部署前应确认允许这一用途。没有 Key、接口超时或返回格式异常时，上传仍然成功，分类回退到后缀规则，页面显示真实的分析来源与状态。

接口依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/) 使用 `/chat/completions` 和结构化 JSON 输出。模型名称可通过环境变量调整，无需改代码。

## 辅助审核（默认关闭）

个人自用或小范围内部使用通常无需强制审核；有开放注册、公开分享和运营管理需求时，辅助审核能帮助管理员发现需要检查的文件。

管理员可在审核页面切换辅助审核，设置保存到数据库，优先于环境变量默认值。开启后，对新上传或重新分析的文件产生辅助标记；既有文件需要重新分析才会得到新结果。关闭后停止新任务的辅助审核判断。

模型只提供疑似风险提示，不能代表完整内容审核，也不会自动生成“人工通过”。管理员查看提示后可手动通过或驳回，保存原因。没有 Key、分析失败或只分析了文件名时，不会冒充已完成内容审核。人工结果会保留。

本次功能是辅助标记与人工复核，不自动删除文件，也不限制文件下载或公开分享；如后续需要公开网盘强制审核，应另行设计发布前拦截、申诉、审计及专用内容检测流程。

## 验证

```powershell
cd clouddrive
mvn -B -Dmaven.repo.local=C:/Environment/m2repo test
cd ../clouddrive-ui
npm run build
```

真实邮箱手工冒烟检查：先启动服务，再执行 `clouddrive/smoke.ps1 -AliceEmail <未注册邮箱1> -BobEmail <未注册邮箱2>`，按提示输入实际收到的验证码。脚本会创建测试账号与文件，不要用正式业务账号运行。

MySQL/Redis 集成测试需要专用空测试库，可通过 `CLOUD_DRIVE_TEST_DB_*`、`CLOUD_DRIVE_TEST_REDIS_*` 环境变量配置，然后运行 `mvn test -DexcludedGroups=`。测试会清空测试库中的业务表，不能配置为正式库。

Windows JDK 17 在部分中文用户临时路径下会出现 `Unable to establish loopback connection`。`run.ps1`、`build.ps1` 已为 Java 进程指定独立的系统临时套接字目录。手工执行 Java 或 Maven 时遇到同样问题，可添加 `-Djdk.net.unixdomain.tmpdir=C:/Windows/Temp`（Maven 测试使用 `-DargLine=-Djdk.net.unixdomain.tmpdir=C:/Windows/Temp`）。此参数仅影响当前进程，不改系统配置。
